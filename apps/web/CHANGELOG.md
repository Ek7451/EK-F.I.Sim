# Longview Planner changelog

## 0.2.0

Released November 26, 2026

- **Starting partway through a year.** For supported plans, you can enter opening balances as of the first of a month and record wages, deferrals and taxes already paid. Plans with healthcare, benefits, property or debt still need January opening balances.
- **Financial independence and historical results.** The headline and milestone now use the same opening balances and recurring spending. The history view shows when there are no complete periods to compare.
- **Healthcare and payroll.** Premiums and Marketplace credits follow the months each person is covered. Payroll contributions account for multiple accounts drawing from the same wages.
- **Backups and cloud saving.** You can review an import and choose how to handle duplicate plans. Account creation and password reset ask you to save your recovery code before the change takes effect.
- **Checking your version.** Settings now links the installed app version to this changelog. The [production release manifest](/release.json) also lists the published version and build revision.
- **Using a phone.** Cash Flow controls wrap on narrow screens. Menus, field help and breakdowns stay within the visible area and scroll when needed. Editors use larger text, and touch gestures keep the interface at its normal scale.

## 0.1.0

Earlier builds used this version number, including the first production deployment of the R3 planning changes described above. Version 0.2.0 gives those changes a distinct release number.
